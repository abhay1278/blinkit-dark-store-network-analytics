# Blinkit Dark-Store Network Analytics

## 📊 Business Analytics | Operations Analytics | Decision Intelligence

An end-to-end Business Analytics project evaluating the performance of a simulated Blinkit dark-store network and translating operational and financial data into actionable store-level decisions.

The project analyses **demand, fulfilment, inventory, customer behaviour, unit economics and capacity** to determine whether stores should be **Expanded, Optimised, Consolidated or Paused**.

> **Academic Project Notice:** This project uses a synthetic dataset provided for academic purposes. The data does not represent actual Blinkit internal data or confidential company information.

---

## 🎯 Business Problem

Dark-store networks need to balance:

- Customer demand
- Delivery speed
- Inventory availability
- Customer retention
- Capacity utilisation
- Delivery costs
- Discounts
- Store-level contribution

The objective of this project was to answer:

> **Which dark stores should Blinkit expand, optimise, consolidate or pause while maintaining service quality and healthy unit economics?**
